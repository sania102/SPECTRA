# 3-minute demo script

Record the screen with the project running locally (video quality is not judged).

| Time | Show | Say |
|---|---|---|
| 0:00–0:15 | Home page | "Search shows information, but not what you're missing. SPECTRA compares Google News, Trends, Jobs, Shopping and more through SerpApi and finds the blind spots." |
| 0:15–0:35 | Type *"Is humanoid robotics actually commercially mature?"*, choose **Deep**, click Run | "An AI agent plans which SerpApi engines to call." |
| 0:35–1:15 | Live pipeline | "Each card is a real SerpApi search running in parallel." |
| 1:15–1:50 | **Answer** card | "A direct answer, the evidence for and against, what we can't conclude, and next steps." |
| 1:50–2:20 | Signal map + blind spots | "Attention is high but hiring and products are low: that gap is the blind spot." |
| 2:20–2:45 | *Evidence* and *Regions* tabs (run the silver question) | "Direction is counted by unique source, and Global vs India are compared side by side." |
| 2:45–3:00 | *Data source & audit* tab | "Every result is live SerpApi data. The AI only writes wording, never scores." |

Tip: run your demo questions once beforehand; repeated identical searches are cached and finish faster.
